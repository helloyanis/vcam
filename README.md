# vCam browser extension

> [!NOTE]  
> This project is a prototype made with artificial intelligence. I just wanted to prototype the fact that you could make a virtual camera app from a browser extension, but it may be buggy or have some performance issues!

Use any of your windows or tabs as camera output for websites to use!

Install it, and open it to configure it!

**Settings description**
- `vCam enabled` : Makes sites able to see vCam or not.
- `Disable real cameras` : Makes sites unable to see any actual cameras you might have, aside from vCam
- `Camera type` : Switches vCam between being a front and back camera. Some sites require one or the other
- `Camera name` : Will change the camera name that websites can see. Useful if a site detects and blocks vCam
- `Start video feed / Stop video feed` : Starts vCam. It's performance heavy, though! Keep the vCam window open otherwise your virtual camera will freeze!
